# Fluxcord Frontend

Basic static frontend for Fluxcord — Master AI & Build Your Future.

## Files
- index.html
- style.css
- script.js
- terms.html
- privacy.html
- assets/logo.png (নিজের logo এখানে রাখুন)

## Run
কোনো build step নেই। `index.html` browser-এ খুললেই কাজ করবে।

Production-এর জন্য VS Code Live Server, Netlify, Cloudflare Pages, GitHub Pages বা আপনার নিজের hosting ব্যবহার করতে পারেন।

## Important
`assets/logo.png` আপনার নিজের Fluxcord logo দিয়ে প্রতিস্থাপন করুন।

`index.html`-এর social links, refund/contact links এবং marketing statistics প্রকাশের আগে নিজের verified information দিয়ে আপডেট করুন।
